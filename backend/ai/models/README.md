# Models

MediaPipe models for the vision pipeline. They are not committed; download
them with:

```bash
./scripts/download_models.sh
```

| File | Model |
|---|---|
| `pose_landmarker.task` | Pose Landmarker (lite), 33 body points |
| `face_landmarker.task` | Face Landmarker, 478 face points with iris and blendshapes |
